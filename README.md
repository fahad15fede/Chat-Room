💬 Java Chat Application

A real-time desktop chat application built using JavaFX and PostgreSQL, designed with clean Object-Oriented Programming principles and client–server communication concepts.
The project simulates a modern chat room environment with dynamic messaging, room management, and interactive desktop UI components.

🚀 Features
Real-time messaging system
Dynamic chat room creation and management
User presence indicators (online/offline status)
Editable room settings and room information dialog
Modern JavaFX-based desktop interface
Interactive message bubbles and smooth UI flow
PostgreSQL database integration for persistent data storage
Modular Object-Oriented backend architecture
Client–server communication concepts implementation
Structured and scalable project organization

PostgreSQL stores user and messaging-related data
JavaFX provides responsive desktop interaction and UI rendering
